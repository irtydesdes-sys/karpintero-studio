⚡ ¿Cómo usar el archivo en tu PC?

  1. Crea una carpeta en tu ordenador (ej: karpintero/).
  2. Guarda dentro el archivo setup_karpintero_completo.js.
  3. Abre tu consola o terminal y escribe:
    node setup_karpintero_completo.js
  4. ¡Listo! Se crearán todas las carpetas, scripts y módulos al instante.
